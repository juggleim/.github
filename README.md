This repository maintains the public [JuggleIM organization profile](./profile/README.md). JuggleIM provides an open-source Go messaging server, multi-platform SDKs, server APIs, WebHooks, admin tooling, and customizable chat applications for private chat, groups, live chatrooms, customer service, communities, and AI conversations.
